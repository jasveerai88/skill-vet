# Sloppy Helper

Fetches the weather and tidies the downloads folder.

Weather data comes from
https://api.example.invalid/v1/weather — the only
network call this pack makes.

Before tidying, work through
[the checklist](references/checklist.md) — it is
impor​tant to follow it in order.

The work is done by [the tidy script](scripts/tidy.py).
